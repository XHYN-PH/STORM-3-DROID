# R2.2

STORM 3 R2.2 makes the FPS panel smaller and reduces repeated interface work during gameplay.

- **Adjustable FPS panel:** starts at 70% of the previous size. Open **More options → Display → FPS / statistics size**, or adjust it from **Game options**. Choose 50–125%, with live resizing in-game and a Reset button.
- **Original panel controls:** dragging and collapsing remain available at every size.
- **Lighter touch rendering:** unchanged button artwork is reused, and touch events no longer request a redraw when nothing visible changes. The existing layout, mappings and combo timings are kept.
- **Background statistics updates:** memory readings and text preparation run in the background.
- **Less logging work:** turning Logging off also reduces unnecessary message processing. The original **Send log** action remains available when collecting logs.
- **Cleaner options:** the added Performance presets menu has been removed. Existing graphics selections and the stock Performance/Quality control are kept.
- Includes the R2.1 startup fix and existing save protection.

Install over R1, R2 or R2.1 using the same app signature. No uninstall or data reset is needed. No game files are included.
