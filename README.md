# STORM 3 — R2 device-test build

**Modified and Translated by XHYN_PH**

Download **STORM-3-R2-arm64.apk** and check SHA256SUMS.

R2 adds an invisible right stick, a controller diagram and reset controls,
save export/backups, vibration controls, proportional fullscreen crop and
additional settings while keeping the stock interface. The app has a circular
gold Leaf icon and is named STORM 3.

The 100% save is preserved. Backup restore is blocked while it is active.
R2 uses the same signing key as R1 and can update it without uninstalling.
Back up saves before updating. Game files are not included.

This is a device-test build. Gameplay, Xbox hardware, game-triggered rumble and
Vulkan crop behavior still need phone testing. True ultrawide rendering is not
implemented; Crop fills the screen by cutting off part of the image.
R1 remains the published release.
