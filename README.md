# R1 signed candidate APK

Modified and Translated by XHYN_PH.

Download STORM-3-DROID-R1-arm64.apk from this branch and verify SHA256SUMS.
This is a candidate for device testing, not a fully validated stable release.
The build, signing, source integrity and 70 host logging assertions passed.
Android logging integration and physical gameplay/GPU tests are still pending.

Back up saves/settings before replacing an upstream installation. R1 has a
new signing key and cannot update an APK signed by another developer.
No game files are included. Existing engine/third-party rights are retained.
