# STORM 3 — refined R2 test build

**Modified and Translated by XHYN_PH** · [YouTube](https://youtube.com/@xhyn_ph)

Download **STORM-3-R2-arm64.apk**. Install it as an update over R1 or an earlier R2 build; it uses the same signing key. Back up saves before updating. No game files are included.

## What's new

- Rounded dark dialogs, clearer settings and gold accents.
- Balanced 720p / 900p presets, automatic display-rate matching and less background polling/animation work.
- Expanded game options with display mode, FPS, touch visibility, opacity and brightness.
- **Return to launcher** stays visible while options scroll. Wait for saving to finish before confirming; unsaved progress can be lost.
- Original controller mapping and touch layout restored.
- Save export/share and protected backup management remain available.

Added right-stick/R3 tools, controller previews/resets, rumble controls, performance history and diagnostics export have been removed.

The bundled 100% save remains protected. Restore is blocked while it is active, and the current save is backed up before restoration.

This is a device-test build. Actual gameplay performance, native shutdown/save completion and Vulkan crop behavior still need phone testing. Crop fills the screen by cutting off part of the image; it does not widen the game camera. R1 remains the published release.
